# Caja de herramientas abiertas para periodistas

Catálogo de recursos abiertos para apoyar tareas de investigación, búsqueda de fuentes, consulta de datos, archivos e imágenes en el trabajo periodístico. Es una iniciativa de **Wikimedia Chile**, desarrollada desde el programa **COALCO** (Comunicaciones y Comunidad).

**Estado:** El recurso puede encontrarse aquí [wikimedia.cl/caja-herramientas-periodistas](https://wikimedia.cl/caja-herramientas-periodistas/)

## Estructura

- `index.html`: página para visualizar la caja en un navegador y contenido HTML que se incorpora en WordPress.
- `styles.css`: presentación, tipografía, colores y estilos responsivos.
- `script.js`: catálogo de herramientas y funcionamiento del buscador, los filtros y el menú móvil.

## Ver la página localmente

Descarga o clona el repositorio y abre `index.html` en un navegador. Los enlaces a `styles.css` y `script.js` son relativos, por lo que los tres archivos deben mantenerse juntos en la misma carpeta. No requiere instalación de dependencias ni compilación.

También puedes usar **Live Server** de Visual Studio Code si quieres que los cambios se actualicen al guardar.
